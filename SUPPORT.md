# Obtenir de l'aide

- Consultez d'abord le `README.md` et les issues existantes.
- Pour une question d'utilisation, ouvrez une discussion GitHub si cette fonctionnalité est activée; sinon, ouvrez une issue avec le modèle approprié.
- Pour une vulnérabilité, suivez `SECURITY.md` et ne publiez pas les détails dans une issue.
- Ne joignez jamais de PDF de travail réel, de secret ou de donnée personnelle à une demande d'aide.

Ce projet communautaire est fourni sans garantie de délai de réponse ni de soutien professionnel.
